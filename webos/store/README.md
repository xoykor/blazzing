# Seller Lounge assets

This directory contains distribution assets that are not packaged into the webOS IPK.

## Current candidate

- `blazzing-icon-400-candidate.png`: 400×400 PNG derived from the packaged 130×130 app icon.

The 400×400 file is a **candidate**, not a final approved store asset. Before submission:

- review the icon visually at 400×400 and thumbnail sizes;
- confirm the current Seller Lounge icon requirements;
- replace/rename the candidate if a dedicated store composition is preferred;
- prepare the required screenshots and other store artwork;
- keep packaged `icon.png` (80×80) and `largeicon.png` (130×130) separate from store-only assets.
